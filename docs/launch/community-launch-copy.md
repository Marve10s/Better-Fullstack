## Show HN

**Title**

> Show HN: Better Fullstack – a visual stack compiler across eight ecosystems

**Opening comment**

> I kept losing the first part of new projects to the same work: picking compatible libraries, wiring the boundaries between them, and then explaining the choices to a coding agent.
>
> Better Fullstack turns those choices into a typed stack plan shared by a visual builder, CLI, preview system, and MCP server. It currently covers TypeScript, React Native, Rust, Python, Go, Java, Elixir, and .NET.
>
> The difficult part has not been generating files. It has been keeping option metadata, compatibility rules, URL state, CLI flags, and generated output synchronized as the surface grows. We publish a benchmark and verified reference combinations, and we are deliberately changing the wording from “every combination is production-ready” to a more honest contract: the full surface is compatibility-aware, while named reference stacks are tested end to end.
>
> You can try the builder without an account: https://better-fullstack.dev/new?utm_source=hacker_news&utm_medium=community&utm_campaign=oss_launch_2026
>
> I would especially value feedback on the compatibility model, generated project boundaries, and what evidence you expect before trusting a scaffold.
