# Better Fullstack launch pack

This folder contains operator-facing launch material. Public, reusable copy and media live at `/press` on the website.

## Before every submission

1. Update the dated adoption metrics in `vercel-oss-application.md` from the public GitHub, npm, and Better Fullstack stats endpoints.
2. Verify every linked demo without signing in.
3. Use “compatibility-aware” for the full option surface. Use “verified” only for reference stacks that passed the published validation gates.
4. Add campaign parameters to outbound links, using `utm_source`, `utm_medium`, and `utm_campaign`.
5. Confirm the PostHog project is still on the free plan without a payment card, or has a product analytics billing limit of `$0`.
6. Be available to answer technical questions for the first several hours after a community launch.

## Files

- `analytics.md` — zero-cost PostHog setup and the initial funnel.
- `vercel-oss-application.md` — application narrative and evidence checklist.
- `community-launch-copy.md` — channel-specific launch drafts.
