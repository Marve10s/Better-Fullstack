TypeScript — це найширша екосистема Better Fullstack. Використовуйте його для веб-програм, API, робітників, оболонок робочого столу, розширень браузера, сайтів документації, інтеграції служб і більшості робочих процесів надбудов.

Мобільні каркаси React Native/Expo живуть у виділеній екосистемі [React Native](/docs/ecosystems/react-native/).

## передумови

- Node.js 20+.
- npm, pnpm, Yarn або Bun.
- Git, якщо ви хочете ініціалізувати сховище.

## Приклад сценарію

```npm
npm create better-fullstack@latest my-app -- \
  --ecosystem typescript \
  --frontend tanstack-router \
  --backend hono \
  --runtime node \
  --database sqlite \
  --orm drizzle \
  --db-setup none \
  --api orpc \
  --auth better-auth \
  --addons turborepo \
  --examples none \
  --ai-docs none \
  --version-channel stable \
  --no-install
```

## Примітки щодо сумісності

- tRPC для інтерфейсів на основі React.
- Сервер `self` призначений для фреймворків із повним стеком і пар із `runtime none`.
- Qwik, Angular, Redwood і Fresh мають вужчу підтримку API/backend, ніж повна таблиця параметрів.
- Підтримка середовища виконання Workers залежить від серверної частини.
- Бібліотеки інтерфейсу користувача часто залежать від сімейства зовнішніх інтерфейсів і фреймворку CSS. Наприклад, shadcn/ui орієнтований на React і базується на Tailwind.
- Деякі провайдери мають додаткові обмеження, наприклад Polar вимагає Better Auth та веб-інтерфейс.
- Деякі параметри з’являються для підтримки сумісності або залежностей, перш ніж кожен шлях шаблону буде однаково глибоким. Запустіть засіб перевірки сумісності або Stack Builder перед створенням великих комбінацій.
