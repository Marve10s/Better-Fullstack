Проекти Rust використовують Cargo і шаблони рідної мови. Виберіть параметри Rust для серверних служб, CLIs, GraphQL/gRPC, інтерфейси WebAssembly, журналювання, кешування та помічники авторизації.

## передумови

- Rust toolchain і Cargo.
- Git, якщо ви хочете ініціалізувати сховище.

## Приклад сценарію

```npm
npm create better-fullstack@latest my-rust-api -- \
  --ecosystem rust \
  --rust-web-framework axum \
  --rust-orm sqlx \
  --rust-libraries serde validator \
  --rust-logging tracing \
  --rust-error-handling anyhow-thiserror \
  --rust-api none \
  --rust-frontend none \
  --rust-cli none \
  --rust-caching none \
  --rust-auth none \
  --rust-realtime tokio-tungstenite \
  --rust-message-queue lapin \
  --rust-observability opentelemetry \
  --rust-templating askama \
  --ai-docs none \
  --version-channel stable \
  --no-install \
  --no-git
```

## Сформована поведінка

- `cargo build` — це шлях встановлення/перевірки, якщо інсталяцію ввімкнено.
- Файли шаблонів Leptos, Dioxus, Tonic, Clap і Ratatui включені лише тоді, коли вибрано відповідні параметри.
- `rustLibraries` є множинним вибором; передайте `none` або пропустіть непотрібні бібліотеки.
- Файли інструкцій AI все ще доступні через `--ai-docs`, включаючи `--ai-docs none`.
