title: AI Агенти
description: Як агенти кодування AI повинні використовувати Better Fullstack безпечно та надійно.
---

Better Fullstack підтримує три робочі процеси AI:

- Створюйте локальні файли інструкцій проекту за допомогою `--ai-docs`.
- Установіть навик агента Better Fullstack, щоб агенти кодування використовували CLI замість рукописного початкового файлу.
- Нехай агент кодування AI використовує сервер Better Fullstack MCP для пошуку схеми, перевірки сумісності, тестування та створення проекту.

## Бажаний робочий процес

1. Виберіть цільову екосистему: `typescript`, `react-native`, `rust`, `python`, `go`, `java` або `elixir`.
2. Використовуйте навички агента Better Fullstack, сервер MCP або явне посилання CLI.
3. Перевірте сумісність перед встановленням риштувань.
4. Перевірте дерево файлів.
5. Скаффолд із встановленням залежностей вимкнено, коли агент керує потоком.
6. Повідомте користувачеві точні команди встановлення, тестування та запуску.

## Створено AI документів

Використовуйте `--ai-docs` для створення файлів локального контексту проекту для агентів кодування:

| Значення | Файл створено |
| --- | --- |
| `claude-md` | `CLAUDE.md` |
| `agents-md` | `Agents.md` |
| `cursorrules` | `.cursorrules` |
| `none` | Ні AI документів |

Приймаються кілька значень:

```npm
npm create better-fullstack@latest my-app -- --ai-docs claude-md agents-md
```

Використовуйте `--ai-docs none`, щоб вимкнути ці файли.

## CLI робочий процес

Для агентів без доступу MCP передайте явні позначки та уникайте побічних ефектів:

```npm
npm create better-fullstack@latest my-app -- \
  --ecosystem typescript \
  --frontend next \
  --backend self \
  --runtime none \
  --database postgres \
  --orm drizzle \
  --auth better-auth \
  --api trpc \
  --db-setup none \
  --ai-docs agents-md \
  --version-channel stable \
  --no-install \
  --no-git
```

<Callout kind="info" title="CLI rules for agents">
`--yes` приймає значення за замовчуванням і несумісний із прапорцями основного стеку. Явні прапори пропускають лише категорії, які вони охоплюють. Передайте `none` для додаткових категорій, які ви хочете вимкнути.
</Callout>

## Робочий процес навичок агента

Навички агента Better Fullstack живуть у цьому репозиторії та навчають підтримуваних агентів використовувати CLI з порівняльним швидким робочим процесом: зіставити стек, запустити пробний запуск, створювати каркаси без встановлення або побічних ефектів Git, а потім повідомляти про подальші команди.

Перегляньте [посібник із налаштування навичок агента](/docs/ai/skills/) для команд встановлення Codex, Claude Code, Cursor, GitHub Copilot та Gemini CLI.

## Параметри постачальника AI

Проекти TypeScript можуть вибрати одну опцію AI з `--ai`: `vercel-ai`, `mastra`, `voltagent`, `langgraph`, `openai-agents`, `google-adk`, `modelfusion`, `langchain`, `llamaindex`, `tanstack-ai`, `ai-cli` або `none`.

Проекти Python використовують окремий параметр множинного вибору `--python-ai` з `langchain`, `llamaindex`, `openai-sdk`, `anthropic-sdk`, `langgraph`, `crewai` або `none`.

Розміщення залежностей залежить від вибраного фреймворку та серверної частини. Пакети на стороні сервера додаються до пакета сервера або додатка власного сервера; підтримувані зовнішні інтеграції отримують відповідні клієнтські хуки або пакети.

## MCP робочий процес

Сервер Better Fullstack MCP надає пошук схеми, перевірку сумісності, попередній перегляд, створення проекту та додавання функцій як структуровані інструменти. Перегляньте [MCP посібник із налаштування](/docs/ai/mcp/).

Це відрізняється від аддона створеного проекту `mcp`. Сервер допомагає агенту створювати проекти Better Fullstack; аддон записує конфігурацію MCP в створений проект.
