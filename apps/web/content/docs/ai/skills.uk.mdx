Навичка агента Better Fullstack вчить агентів програмування використовувати CLI замість рукописного написання початкових проектів. Він зіставляє запитуваний стек із частинами графіка, спочатку запускає сухий запуск, скелети з вимкненою інсталяцією залежностей і повідомляє про точні подальші команди.

Використовуйте це, якщо ваш агент підтримує навички, і вам потрібен найшвидший шлях від підказки до створеного проекту Better Fullstack. Використовуйте [MCP сервер](/docs/ai/mcp/), якщо натомість вам потрібен пошук структурованої схеми та планування викликів інструментів.

## встановити

Навички живуть у цьому сховищі за адресою `.agents/skills/better-fullstack`. Оскільки репо також містить інші внутрішні навички, інсталюйте лише `better-fullstack`.

Встановити для Codex:

<PMTabs
  npm="npx skills@latest додати Marve10s/Better-Fullstack --skill better-fullstack --agent codex --global --yes"
  pnpm="pnpm dlx skills@latest додати Marve10s/Better-Fullstack --skill better-fullstack --agent codex --global --yes"
  bun="bunx skills@latest add Marve10s/Better-Fullstack --skill better-fullstack --agent codex --global --yes"
  yarn="yarn dlx skills@latest add Marve10s/Better-Fullstack --skill better-fullstack --agent codex --global --yes"
/>

Встановити для кількох поширених агентів:

```bash
bunx skills@latest add Marve10s/Better-Fullstack \
  --skill better-fullstack \
  --agent codex claude-code cursor github-copilot gemini-cli \
  --global \
  --yes
```

Для локального встановлення проекту пропустіть `--global` з тієї ж команди. Встановлення проекту корисно, коли команда хоче, щоб версія навичок була записана в репозиторії.

## використання

Явно викликайте навик:

```text
Use $better-fullstack to create a React + Vite app with Hono, SQLite, Drizzle, tRPC, Tailwind, DaisyUI, Pino, Vitest, and Biome.
```

Або запитайте природно. Агенти, які підтримують неявне зіставлення навичок, можуть вибрати навички, коли запит стосується будівництва лісів, планування або розширення проекту Better Fullstack.

## Що робить майстерність

1. Відображає запитаний стек у Better Fullstack частини графа та CLI прапори.
2. Запускає неінтерактивний сухий прогін CLI.
3. Виконує ту саму команду без `--dry-run`, коли план вдається.
4. Використовує `--no-install` і `--no-git`, якщо ви явно не запитуєте ці побічні ефекти.
5. Повідомляє про використану команду, будь-які налаштування сумісності та наступні команди встановлення/тестування/запуску.

## Навички проти MCP

| шлях | Найкраще для |
| --- | --- |
| Агентська майстерність | Швидкий каркас, керований CLI, коли стек можна виразити у вигляді прапорців або частин графа. |
| MCP сервер | Пошук у структурованій схемі, перевірка сумісності, планування пробій і зміна існуючого проекту за допомогою викликів інструментів. |

Обидва шляхи використовують той самий генератор Better Fullstack. Майстерність - це легший шлях; MCP є більш структурованим маршрутом.
