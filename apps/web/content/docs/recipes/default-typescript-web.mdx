Use this recipe when you want the shortest path to the supported default: TanStack Router, Hono,
Bun, SQLite, Drizzle, Better Auth, tRPC, Tailwind CSS, shadcn/ui, Vitest, and Turborepo.

## Prerequisites

- Node.js 20 or newer.
- Bun for the generated project's default runtime and package manager.

## Scaffold

<PMTabs
  npm="npm create better-fullstack@latest my-app -- --yes --package-manager bun --no-install --no-git"
  pnpm="pnpm create better-fullstack@latest my-app --yes --package-manager bun --no-install --no-git"
  bun="bun create better-fullstack@latest my-app --yes --package-manager bun --no-install --no-git"
  yarn="yarn create better-fullstack@latest my-app --yes --package-manager bun --no-install --no-git"
/>

The command pins Bun as the generated package manager and creates frontend and backend workspaces
plus `bts.jsonc` and `bts.lock.json`. Skipping install and Git makes the scaffold easy to inspect.

## Install and run

```bash
cd my-app
bun install
bun run dev
```

Open the local URL printed by the dev command. Stop the server before running verification in the
same terminal.

## Verify and continue

```bash
bun run check-types
bun test
```

Commit the initial scaffold. To add a capability, preview it first—for example
`bun create better-fullstack@latest add --email resend --dry-run`.
