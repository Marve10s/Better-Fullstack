Use Stack Parts when one product spans languages or deployable applications. This recipe creates a
TypeScript web frontend, a Go backend with GORM, a shared PostgreSQL database, and a React Native
mobile app.

## Prerequisites

- Node.js 20 or newer and Bun.
- Go.
- PostgreSQL or Docker for a local database.
- Expo-compatible mobile tooling when running the mobile app.

## Inspect before running

Open `bts.jsonc` and confirm the `stackParts` owners. Each generated app has its own README and
toolchain commands; install the JavaScript workspaces with `bun install` and the Go service with
`go mod tidy` when its README asks for it. Configure the shared database URL in each generated
`.env` file before starting services.

## Verify and evolve

Run each app's generated test/build command, then run
`bun create better-fullstack@latest check` at the project root. Preserve stable part IDs when adding
multiple backends so owned capabilities continue to target the intended service.
