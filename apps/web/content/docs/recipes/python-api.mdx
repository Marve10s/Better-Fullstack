## Install, run, and verify

```bash
cd python-api
uv sync --extra dev
uv run uvicorn app.main:app --reload
```

Open the URL printed by Uvicorn and check `/docs` for FastAPI's API explorer. Then stop the server
and run:

```bash
uv run ruff check .
uv run pytest
```

The generated README is authoritative if its module path differs because of a later template
version.
