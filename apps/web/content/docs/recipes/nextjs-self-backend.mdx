This stack keeps the server inside Next.js instead of generating a separate backend workspace.

## Prerequisites

- Node.js 20 or newer and a package manager.
- A PostgreSQL database URL for local development.

## Configure and run

```bash
cd next-app
bun install
cp .env.example .env
```

Set the PostgreSQL and auth values described in `.env.example`, then run `bun run dev`. The result
is one fullstack Next.js application; `backend self` and `runtime none` are intentional.

## Verify

Run `bun run check-types`, the generated test command, and
`bun create better-fullstack@latest check`. Use the
[environment-variable setup guide](/docs/provider-setup/environment-variables) when adding hosted
auth, email, payments, or storage.
