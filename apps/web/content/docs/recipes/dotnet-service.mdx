## Restore, configure, and run

```bash
cd dotnet-api
dotnet restore
dotnet run
```

Set the development connection string in `appsettings.json`, a local configuration override, or
the `ConnectionStrings__DefaultConnection` environment variable. Open the URL printed by ASP.NET
Core and use the generated `.http` file for request examples.

## Verify

```bash
dotnet build
dotnet test
```

EF Core creates code and provider configuration, but application data and production migrations
remain your responsibility.
