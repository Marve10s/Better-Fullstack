Цей розділ керує поверхнями додатків для користувача, які створює Better Fullstack.

## Веб-інтерфейс

Веб-інтерфейси TypeScript вибираються за допомогою `--frontend`. Категорія підтримує React, Vinext, Vue/Nuxt, SvelteKit, Solid, Astro, Qwik, Angular, Redwood, Fresh і `none`.

Використовуйте `none` лише для серверних служб. Використовуйте інтерфейсні режими повного стеку з `--backend self`, коли структура володіє серверними маршрутами.

## React Native програми

React Native — це власна екосистема. Виберіть його за допомогою `--ecosystem react-native` або як мультиекосистемну частину за допомогою `mobile:react-native:native-bare`.

Вибір для мобільних пристроїв включає навігацію, інтерфейс користувача, сховище, тестування, push-сповіщення, оновлення OTA та глибокі посилання. Вони не передбачають TypeScript веб-сервера або категорії розгортання.

## Rust Інтерфейси WASM

Rust може генерувати зовнішні поверхні Leptos або Dioxus через `--rust-frontend`. Це вибір екосистеми Rust, окремий від веб-інтерфейсів TypeScript.

## Платформи додатків

Аддони до платформи додатків, такі як Tauri, PWA, WXT і OpenTUI, додають можливості оболонки, офлайн, розширення або термінальні програми навколо сумісних стеків.
