Вибір інтерфейсу користувача та досвіду формує згенерований інтерфейсний код, примітиви дизайну та шаблони програм на стороні клієнта.

## Бібліотеки стилів та інтерфейсу користувача

Вибір CSS включає Tailwind, SCSS, Less, PostCSS-only або жодного. Бібліотеки інтерфейсу користувача включають shadcn/ui, shadcn-svelte, daisyUI, Radix UI, Headless UI, Park UI, Chakra UI, NextUI, Mantine, MUI, Ant Design, Base UI, Ark UI, React Aria та жодної.

shadcn/ui має додаткові стилі для базових примітивів, візуального стилю, піктограм, колірної теми, нейтрального базового кольору, шрифту та радіуса.

## Форми, перевірка та стан

Варіанти зовнішніх додатків включають:

- Стан: Zustand, Jotai, Nanostores, Redux Toolkit, MobX, XState, Valtio, TanStack Store, Legend State або жодного.
- Форми: TanStack Form, React Hook Form, Formik, Final Form, Conform, Modular Forms або жодної.
- Перевірка: Zod, Valibot, ArkType, TypeBox, Typia, Runtypes, Effect Schema або жодної.

## Особливості досвіду

Анімація, i18n і суміжні з зовнішнім інтерфейсом аддони платформи програми живуть тут концептуально, навіть якщо їхні точні прапорці з’являються в різних таблицях параметрів.

React Native має власні варіанти мобільного інтерфейсу користувача: Tamagui, Gluestack UI, Uniwind, Unistyles або жодного.
