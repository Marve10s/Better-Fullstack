Better Fullstack — це генератор проектів для типізованих стеків продуктів. Виберіть інтерфейс, бекенд, рівень даних, служби, інструменти та цільову екосистему; CLI записує відповідні файли та записує стек у `bts.jsonc`.

Використовуйте інтерактивний CLI, коли вам потрібна керована настройка, [Stack Builder](__BFS0__), коли ви хочете візуально порівняти параметри, і явні позначки, коли вам потрібна відтворювана команда для CI, документів або іншого розробника.

## Вимоги

CLI працює на Node.js 20 або новішої версії.

```bash
node --version
```

Створені проекти також можуть потребувати свого екосистемного інструментарію: інструменти Expo для React Native, Cargo для Rust, `uv` для Python, Go, Java 21 або Elixir/Erlang для Phoenix проекти.

## Створіть свій перший проект

Запустіть майстер і дайте відповіді на підказки:

```npm
npm create better-fullstack@latest my-app
```

Для npm прапорці Better Fullstack йдуть після розділювача `--`. Відображені вкладки менеджера пакунків показують відповідні команди pnpm, Bun та Yarn, де роздільник не потрібен.

## Що створюють значення за замовчуванням

Прийняття типових значень створює проект TypeScript з:

- TanStack Router інтерфейс і Hono сервер.
- Bun виконання, SQLite, Drizzle, Better Auth та tRPC.
- Tailwind CSS, shadcn/ui, Vitest та Turborepo.
- Менеджер пакетів використовувався для запуску CLI, стабільних версій залежностей, Git, увімкнено встановлення та `CLAUDE.md`.

Ви можете зберегти цей стек, почати з шаблону або повністю змінити екосистему.

## Способи вибору стека

| шлях | Використовуйте його, коли |
| --- | --- |
| CLI майстер | Вам потрібні підказки та розумні параметри за замовчуванням. |
| Stack Builder | Ви хочете вивчити сумісні комбінації, перш ніж будувати ліси. |
| Явні прапори | Вам потрібен повторюваний вихід у сценаріях, документах або звітах про проблеми. |
| Навички агента | Ви хочете, щоб агент кодування використовував робочий процес CLI без рукописного написання початкових файлів. |
| MCP сервер | Ви хочете, щоб агент кодування AI перевірив схему, підтвердив сумісність і безпечно провів роботу. |

## Згенерований контекст проекту

Кожен створений проект містить:

- `bts.jsonc` з вибраним стеком.
- Відтворювана команда, надрукована CLI.
- Фреймворк, пакет і файли конфігурації для вибраної екосистеми.
- Додаткові файли інструкцій AI, наприклад `CLAUDE.md`, `Agents.md` або `.cursorrules`.
