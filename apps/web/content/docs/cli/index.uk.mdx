Better Fullstack має невелику командну поверхню. Більшості користувачів потрібні лише `create`, `add`, `check` та `history`; AI-робочі процеси агента використовують `mcp`.

## Команди

| Команда | призначення |
| --- | --- |
| `create` | Створіть новий проект із конфігурації стека. Це команда за замовчуванням. |
| `add` | Додайте підтримувані аддони, налаштування розгортання або можливості стека до існуючого проекту Better Fullstack. |
| `check` | Діагностуйте існуючий проект на наявність проблем із конфігурацією, залежностями, середовищем і згенерованою перевіркою. |
| `doctor` | Псевдонім сумісності для `check`. |
| `history` | Показувати, експортувати або очищати локальну історію скаффолду та відтворювані команди. |
| `mcp` | Запустіть сервер Better Fullstack MCP через stdio для агентів кодування AI. |

## Службові команди

| Команда | призначення |
| --- | --- |
| `docs` | Відкрийте загальнодоступний сайт документації Better Fullstack у своєму браузері. |
| `builder` | Відкрийте інтерактивний Stack Builder. |
| `sponsors` | Показати спонсорів Better Fullstack. |

## Запуск службових команд

Відкрити документи:

<PMTabs
  npm="npx -y create-better-fullstack@latest документи"
  pnpm="pnpm dlx create-better-fullstack@latest документи"
  bun="bunx create-better-fullstack@latest документи"
  yarn="пряжа dlx create-better-fullstack@latest документи"
/>

Відкрийте конструктор:

<PMTabs
  npm="npx -y create-better-fullstack@latest builder"
  pnpm="pnpm dlx create-better-fullstack@latest конструктор"
  bun="bunx create-better-fullstack@latest builder"
  yarn="пряжа dlx create-better-fullstack@latest builder"
/>

Спонсори шоу:

<PMTabs
  npm="npx -y create-better-fullstack@latest спонсори"
  pnpm="pnpm dlx create-better-fullstack@latest спонсори"
  bun="bunx create-better-fullstack@latest спонсори"
  yarn="yarn dlx create-better-fullstack@latest спонсори"
/>

## Команди супроводжуючого

`update-deps` для супроводжувачів, які перевіряють і оновлюють версії залежностей. Його навмисно виключено зі звичайних робочих процесів користувача.
