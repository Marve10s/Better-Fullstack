---
title: "Опції"
description: "Згенероване посилання для параметрів стека Better Fullstack."
---

У цій довідці перераховано значення CLI, прийняті Better Fullstack. Використовуйте ці значення в командах, Stack Builder URL-адресах і MCP корисних даних.

Деякі мітки конструктора нормалізуються до того самого значення CLI, і не кожен параметр є дійсним для кожного інтерфейсу, серверної частини, середовища виконання чи екосистеми. Запустіть перевірку сумісності перед тим, як будувати складні стеки.
