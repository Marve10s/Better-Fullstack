TypeScript — найширша екосистема Better Fullstack. Використовуйте ці значення CLI в командах, корисних навантаженнях MCP і посиланнях Stack Builder.

<Callout kind="info" title="Compatibility notes">
У таблиці наведено дійсні значення, а не кожну дійсну комбінацію. tRPC орієнтований на React. `backend: self` призначений для фреймворків із повним стеком і поєднується з `runtime: none`. Робоче середовище виконання, бібліотеки інтерфейсу користувача, постачальники, аддони та цілі розгортання мають обмеження, пов’язані зі стеком.
</Callout>

Опції React Native і Expo доступні на сторінці [React Native Параметри](/docs/reference/options/react-native/).
