Параметри React Native вибираються за допомогою `--ecosystem react-native`. Вони створюють програму Expo і не розкривають категорії веб-інтерфейсу, серверної частини, бази даних або веб-розгортання TypeScript.

<Callout kind="info" title="Compatibility notes">
`native-uniwind` вибирає `mobile-ui: uniwind`. `native-unistyles` вибирає `mobile-ui: unistyles`. Tamagui і gluestack-ui призначені для `native-bare`, щоб уникнути конфліктних систем стилів.
</Callout>
