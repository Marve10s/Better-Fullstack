## Requirements

[Node.js](https://nodejs.org/en/download) 20 or newer, and only if you run the CLI.

To skip that install, configure the project in the [Stack Builder](/new) and download it as a ZIP. That path needs nothing but a browser.

## After the first scaffold

| What changed?                                                | Use                                                                              |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| You want a new capability or stack selection                 |`add --dry-run`, then`add` after review.                                        |
| The selected stack is unchanged, but templates have advanced |`update`; review, then apply with its exact token and keep its recovery command. |
| You want a supported resource generated inside the project   |`gen ... --dry-run`, then`gen`.                                                 |
| You installed dependencies or changed environment values     |`check`, plus the project's own tests.                                           |
