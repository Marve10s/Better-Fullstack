Використовуйте цей стек, якщо вам потрібна програма Qwik без додавання окремого сервера або бази даних у перший день.

```npm
npm create better-fullstack@latest my-qwik-app -- \
  --ecosystem typescript \
  --frontend qwik \
  --backend none \
  --runtime none \
  --database none \
  --orm none \
  --auth none \
  --api none \
  --css-framework tailwind \
```

## Що це створює

- Додаток Qwik.
- Tailwind CSS.
- За замовчуванням немає рівня бази даних, ORM, автентифікації чи API.
- Згенеровану конфігурацію проекту можна розширити пізніше.

## Згенерована форма

Цей посібник навмисно починається з програми Qwik City, яка призначена лише для інтерфейсу. Це корисно, коли потрібно, щоб оболонка програми, маршрутизація та стиль були на місці перед вибором серверної частини або рівня збереження.

Представницька форма:

```txt
my-qwik-app/
  bts.jsonc
  src/
    routes/
    components/
```

Згенеровані `bts.jsonc` записи, що серверна частина, час виконання, база даних, ORM, авторизація та API — це `none`. Це робить мінімальну природу стека явною, а не неявною.

## Приклад маршруту

Qwik Міські маршрути можуть починатися з малого:

```tsx
import { component$ } from "@builder.io/qwik";

export default component$(() => {
  return (
    <main class="mx-auto max-w-4xl p-6">
      <h1 class="text-3xl font-semibold">Qwik app</h1>
      <p class="text-slate-600">Add server features when the product needs them.</p>
    </main>
  );
});
```

Зберігайте початкові маршрути, зосереджені на вимогах до інтерфейсу користувача та даних. Додайте бекенд лише тоді, коли є справжня відповідальність на стороні сервера, як-от авторизація, постійність, веб-перехоплення або приватні виклики API.

## Примітки щодо сумісності

Qwik має вужчу підтримку серверної частини/API у Better Fullstack, ніж параметри React, Nuxt, Svelte або Solid. Цей посібник зберігає стек навмисно мінімальним і сумісним.

Оскільки команда використовує `--backend none`, `--database none`, `--orm none`, `--auth none` та `--api none`, вона не повинна створювати контракти сервера або моделі бази даних. Якщо вам це потрібно з першого дня, оберіть пару фреймворк/сервер із повнішою підтримкою Better Fullstack.

## Коли його вибрати

Виберіть Qwik для інтерфейсних додатків, де можливість відновлення та мінімальне початкове корисне навантаження важливіші, ніж згенерований сервер у перший день.

## Додавання бекенда пізніше

Коли програмі потрібні дані, вирішіть, чи має Qwik залишатися зовнішнім інтерфейсом, поки інша служба володіє API, чи інший стиль Better Fullstack краще відповідатиме вимогам повного стеку. Для багатьох команд додавання Hono API як окремої служби є чистішим, ніж переміщення проблем серверної частини в шаффолд, перш ніж інтерфейс.

Корисні майбутні доповнення включають:

- Hono API для логіки приватного сервера.
- PostgreSQL плюс Drizzle або Prisma для реляційних даних.
- Better Auth, коли керування обліковим записом стане частиною продукту.
- oRPC або інший типізований рівень контракту, коли інтерфейсу та API потрібні спільні типи.

## Примітки до розгортання

Мінімальний додаток Qwik легко розгортати як веб-додаток або зовнішній інтерфейс із підтримкою статики, залежно від згенерованого адаптера та цільового хостингу. Оскільки ця команда не додає базу даних або автентифікацію, робоче налаштування здебільшого зосереджується на вихідних даних збірки, маршрутах і змінних публічного середовища.

## Усунення несправностей

- Якщо ви очікуєте файли бази даних, перевірте команду: цей посібник навмисно передає `--database none` та `--orm none`.
- Якщо маршрути авторизації відсутні, стек використовує `--auth none`.
- Якщо класи Tailwind не застосовуються, перевірте згенеровані шляхи вмісту Tailwind та інтеграцію в структуру.
- Якщо пізніше ви додасте API, зберігайте загальнодоступні змінні клієнта окремо від секретів приватного сервера.

## Порівняльні нотатки

Виберіть це, а не Astro, якщо можливість відновлення та модель компонентів Qwik є основними причинами проекту. Виберіть [Astro з React і Hono](/guides/typescript/astro-react-hono/), якщо сторінки вмісту потребують згенерованого серверу Hono та бази даних із самого початку.
