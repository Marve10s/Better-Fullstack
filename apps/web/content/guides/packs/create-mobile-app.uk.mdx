Використовуйте пакет мобільних додатків, коли перший екран має бути нативним, а не веб-сайтом. Він починається з Expo і Uniwind, щоб ви могли створити мобільний інтерфейс перед додаванням серверних служб.

<StarterPackCta id="mobile-app" />

## Згенеруйте мобільний стартер

Відкрийте [пакет мобільних програм у Stack Builder](/new?preset=uniwind&view=command) або запустіть:

```bash
bun create better-fullstack@latest my-mobile-app \
  --ecosystem typescript \
  --frontend native-uniwind \
  --backend none \
  --database none \
  --api none \
  --css-framework none \
  --ui-library none
```

## Що входить до набору

- Expo для рідного середовища виконання програми.
- React Native як основа інтерфейсу користувача.
- Uniwind для нативного стилю на першому місці.
- Форма проекту лише для інтерфейсу, яка залишається легкою, доки не знадобляться вибори для бекенда.

## Перше, що потрібно налаштувати

1. Замініть зразки екранів основним мобільним потоком.
2. Вирішіть, чи має бути автентифікація лише нативною, із підтримкою API чи спільною з веб-програмою.
3. Додайте серверні служби лише після того, як межі даних програми будуть чіткими.
4. Завчасно перевіряйте макети на малих і великих пристроях.

## Коли це правильний пакет

Виберіть це для мобільних продуктів, додатків-супутників, прототипів, які потребують нативного відчуття, і команд, які хочуть почати з досвіду роботи з пристроєм, перш ніж вибрати серверну інфраструктуру.

Щоб отримати інструкцію на рівні стека, прочитайте [Expo Uniwind Native App](/guides/react-native/expo-uniwind-native/).
