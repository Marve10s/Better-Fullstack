## Коли використовувати пакет

Використовуйте пакет, якщо вам потрібен сильний стандарт за замовчуванням і швидкий робочий проект. Після генерації Stack Builder все ще дозволяє налаштовувати структуру, базу даних, авторизацію, API, розгортання та вибір інструментів.

Якщо ви вже знаєте точний стек, скористайтеся натомість [Stack Builder](/new?view=presets) або спеціальним посібником для стека.

## Нотатки щодо вибору упаковки

- Виберіть пакет SaaS, якщо виставлення рахунків, авторизація та електронна пошта є частиною першої версії продукту.
- Виберіть пакет додатків агента AI, коли інструкції агента, MCP і код додатка повинні розвиватися разом.
- Виберіть серверні пакети REST API, Java API або Rust, коли продукт запускається як межа служби.
- Виберіть пакет мобільних додатків, якщо робота з пристроєм має значення перед архітектурою серверної частини.
- Виберіть пакет внутрішніх інструментів, якщо робочі процеси CRUD, інформаційні панелі та автентифіковані операції є продуктом.
